# icloud email domäne für alle familienmitglieder
Diese Seite dokumentiert wie eine Familie, die teils Apple Geräte und teils Windows oder Android Geräte benutzt trotzdem Apple für seine email verwenden kann. Hauptvorteil ist dass der Speicher von z Bsp 2 TB allen zur Verfügung für emails aus Jahrzehnten und Bildern aus Jahrzehnten steht.
